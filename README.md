# Battery IDE

Веб-застосунок для проєктування акумуляторних збірок: генерує схему S×P, вписує її в корпус і містить калькулятори для збирання.

## Можливості

**Конструктор**
- База комірок: 18650, 21700, 14500, 26650, 32700, 4680, LTO, призматичні LiFePO4. Можна додати власні.
- Генерує схему S×P у вигляді сітки, стільників або щільних стільників. Групи укладаються «змійкою» по стовпцях або по рядах.
- Для циліндричних комірок показує вигляд зверху і знизу (перевернутий), для призматичних — розташування клем.
- Позначає полярність кожної комірки, паралельні й послідовні перемички, балансувальні виводи BMS B0…Bn, а також P+ і P−.
- Перевіряє схему: чи суцільні шини, чи є з'єднання між сусідніми групами, чи витримує нікель струм на найслабшій ділянці, чи не перевищено струм комірки.
- Рахує напругу, ємність, енергію, максимальний струм, опір пакета, просідання напруги, тепло, масу й габарити.
- Формує специфікацію (BOM) і покроковий порядок збирання.
- Експортує в SVG і PNG, друкує, зберігає та відкриває проєкт у JSON. Стан автоматично зберігається в браузері.

**Вписування в корпус**
- Підбір S×P: для діапазону S або цільової напруги знаходить максимальний P, що поміщається в корпус L×W×H. Перебирає всі орієнтації (стоячи, лежачи) і всі варіанти розміщення.
- Перевірка, чи поміщається поточна схема.
- Розрахунок мінімального корпусу під поточну схему.
- Враховує відступи до стінок, зазори, запас уздовж осі. Можна дозволити кілька шарів.
- Показує переріз корпусу. Обраний варіант відкривається в конструкторі одним натисканням.

**Калькулятори**
- Підбір конфігурації під напругу, ємність або енергію, тривалий і піковий струм.
- Нікелева стрічка (нікель, нікельована сталь, мідь): опір, падіння напруги, допустимий струм, потрібна кількість шарів.
- Перетин силового дроту (AWG і мм²) за струмом і допустимим падінням напруги.
- Час роботи та час заряду.

**Балансування комірок**
- Вставте виміряні ємності (і за бажання внутрішній опір). Застосунок розподілить комірки по групах так, щоб сумарні ємності груп були якомога рівнішими. Результат можна показати на схемі або вивантажити в CSV.

## Запуск

Застосунок статичний і не потребує збирання чи залежностей. Через ES-модулі його потрібно відкривати з HTTP-сервера, а не через `file://`.

```bash
npm start
```

Після запуску відкрийте http://localhost:8080. Можна також використати `python3 -m http.server` або розмістити файли на GitHub Pages.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` запускає тести і публікує сайт (`index.html`, `css/`, `js/`) при кожному push у `main`. Також його можна запустити вручну на вкладці **Actions** (Run workflow).

Одноразове налаштування: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Адреса сайту: `https://<користувач>.github.io/battery_ide/`.

## Тести

```bash
npm test
```

Тести перевіряють геометрію (немає перекриттів, групи суцільні, послідовні з'єднання є), вписування в корпус, калькулятори, балансування та генерацію SVG.

## Структура

| Файл | Призначення |
|---|---|
| `js/cells.js` | база комірок |
| `js/layout.js` | розташування комірок, групи, шини, характеристики пакета |
| `js/fit.js` | вписування в корпус |
| `js/tools.js` | калькулятори та балансування |
| `js/render.js` | генерація SVG |
| `js/main.js` | інтерфейс |

> Параметри комірок орієнтовні, звіряйте їх з даташитом. Схеми є допоміжними: збирайте акумулятори з BMS і запобіжником, дотримуйтеся техніки безпеки.
