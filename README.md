# Battery IDE

Веб-застосунок для проєктування акумуляторних збірок: генерує схему S×P, вписує її в корпус і містить калькулятори для збирання.

## Можливості

**Конструктор**
- **Типові збірки (пресети)** за популярними конфігураціями: самокат 10S3P, e-bike 10S4P / 13S4P (Hailong) / 14S5P, трикутник у раму 14S6P, скейт 12S4P, e-moto 20S8P, інструмент 5S2P, LiFePO4 12/24/48 В (4S/8S/16S). Пресет задає комірку, S×P, розкладку, перемички, силові виводи, BMS, а для трикутника — одразу вписує пакет у форму.
- База комірок: 18650, 21700, 14500, 26650, 32700, 4680, LTO, призматичні LiFePO4. Можна додати власні.
- Генерує схему S×P у вигляді сітки, стільників або щільних стільників. Групи укладаються «змійкою» по стовпцях або по рядах.
- Режими перегляду схеми:
  - **Схема** — оглядова: кожна паралельна група як кольорова область з номером, стрілки показують шлях струму P− → 1 → 2 → … → P+ (суцільна — з'єднання зверху, пунктир — знизу), позначено місця, де групи торкаються лише однією коміркою.
  - **Збирання** — креслення для зварювання з кроками: 1 · розстановка комірок (полярність), 2 · перемички зверху, 3 · перемички знизу.
  - **Струми** — розрахунковий струм кожної комірки та навантаження перемичок.
  - **Проводка BMS** — точки приварювання балансувальних і силових дротів та їх шлях до BMS.
  - **3D** — об'ємна модель пакета: комірки з полярністю, перемички (за типом або за струмом), BMS із дротами, номери груп, мінімальний корпус, розліт шарів перемичок, готові ракурси, підказки при наведенні, експорт PNG.
- Для циліндричних комірок показує вигляд зверху і знизу (перевернутий), для призматичних — розташування клем.
- Позначає полярність кожної комірки, паралельні й послідовні перемички, балансувальні виводи BMS B0…Bn, а також P+ і P−.
- Змійка груп по стовпцях, по рядах або U-подібна (P+ і P− з одного боку пакета).
- **Яруси** вздовж осі комірок (наприклад, двоярусний пакет для скейта): групи діляться між ярусами, наступний ярус починається над кінцем попереднього, міжярусна перемичка додається автоматично; 2D показує яруси окремо, 3D — стеком.
- **Довільна форма** (з вкладки «Вписування в корпус»): розкладка з позицій, вписаних у трикутник, трапецію чи контур; обхід форми обирається так, щоб було якнайменше розривів і стиків груп в одну комірку.
- **Дроти-перемички**: там, де частини шини не торкаються (форма, яруси), автоматично додається найкоротший ізольований дріт; стик груп в одну комірку (P ≥ 3) підсилюється другою перемичкою. Перетин дроту підбирається за струмом навантаження.
- **Окремі послідовні перемички**: матеріал, ширина й шари для перемичок між групами (вони несуть увесь струм) задаються окремо від паралельних.
- **Силові виводи**: біля BMS, у центрі крайньої групи або **мідна збірна шина по групі** — кожна комірка приварена до шини, силовий дріт підходить до шини. Для e-moto 20S8P при 100 А це зменшує розбаланс струму в групі зі 161% до 14%.
- **Призматичні комірки**: у кількох рядах непарні ряди розвертаються на 180° (шини між рядами з'єднують клеми, звернені одна до одної); у специфікації й кроках — стискання пакета, момент затягування клем, гнучкі шини.
- Показує BMS збоку пакета, точки приварювання балансувальних дротів B0…Bn (найближчі до BMS) і силових виводів P+/P− (біля BMS або в центрі крайньої групи).
- **Розрахунок розподілу струмів**: пакет моделюється як мережа опорів (внутрішній опір комірок + опір кожної перемички). Показує струм кожної комірки, навантаження кожної перемички (підсвітка від зеленого до червоного), розбаланс струму в групах, просідання напруги й тепло. Підказує, де саме потрібен додатковий шар стрічки чи мідна шина.
- Перевіряє схему: чи суцільні шини, чи є з'єднання між сусідніми групами, чи не перевищено струм комірки.
- **Комутація без перетинів.** Точки приварювання балансувальних дротів обираються узгоджено (динамічне програмування): уздовж краю, де стоїть BMS, вони йдуть у тому ж порядку, що й піни роз'єму P−, B0…Bn, P+. Дріт іде від точки перпендикулярно до краю, далі віялом до свого піна — тому дроти не перетинаються. Сторону BMS можна обрати автоматично (найкоротші дроти без перетинів; силові дроти мають більшу вагу); якщо з обраної сторони без перетинів не обійтися, показується попередження і рекомендована сторона. Для U-розкладки дроти можуть іти **центральним каналом** між «банками» до BMS на відкритому кінці U — так розводяться без перетинів навіть пакети LiFePO4 2×8.
- Перевірка оголених шин: зазор між перемичками різних потенціалів на одній стороні та проходження перемички над клемою чужої шини.
- Колінеарні перемички зливаються в суцільні відрізки стрічки — карта нарізки (кількість × довжина з напуском) у специфікації.
- Рахує напругу, ємність, енергію, максимальний струм, опір пакета, просідання напруги, тепло, масу й габарити.
- Формує специфікацію (BOM) і покроковий порядок збирання.
- Експортує в SVG і PNG, друкує, зберігає та відкриває проєкт у JSON. Стан автоматично зберігається в браузері.

**Підключення BMS**
- Електрична схема: групи, балансувальні дроти з напругами, BMS, запобіжник, вимикач, коло передзаряду, навантаження й зарядний порт. Підтримуються BMS зі спільним і роздільним (C−) портом, апаратні та розумні, з невикористаними каналами.
- Таблиця балансувальних дротів: що з'єднує кожен дріт, куди саме приварити (група, ряд, стовпець, сторона), очікувана напруга відносно B0, довжина.
- Пороги захисту під хімію (Li-ion, LiFePO4, LTO, Na-ion): напруга заряду, OVP/UVP з відновленням, початок балансування, напруга зберігання, OCP.
- Підбір струму BMS, запобіжника, перетину силових і зарядних дротів.
- Перевірки (канали, струм, заряд, балансування, датчики температури, передзаряд) і покроковий порядок підключення. Експорт схеми в SVG/PNG.

**Вписування в корпус**
- Підбір S×P: для діапазону S або цільової напруги знаходить максимальний P, що поміщається в корпус L×W×H. Перебирає всі орієнтації (стоячи, лежачи) і всі варіанти розміщення.
- Перевірка, чи поміщається поточна схема.
- Розрахунок мінімального корпусу під поточну схему.
- Враховує відступи до стінок, зазори, запас уздовж осі. Можна дозволити кілька шарів (відкриваються в конструкторі як яруси).
- **Корпус довільної форми**: трикутник (рама велосипеда), трапеція або контур за точками + товщина. Перебираються сітка і стільники, кути повороту й зсуви решітки — максимум комірок, потім підбір S×P.
- Показує переріз корпусу. Обраний варіант відкривається в конструкторі одним натисканням.

**Калькулятори**
- Підбір конфігурації під напругу, ємність або енергію, тривалий і піковий струм (для LiFePO4 «48 В» — 16S, як у інверторах).
- Нікелева стрічка (нікель, нікельована сталь, мідь): опір, падіння напруги, допустимий струм, потрібна кількість шарів.
- Перетин силового дроту (AWG і мм²) за струмом і допустимим падінням напруги.
- Час роботи та час заряду.

**Балансування комірок**
- Вставте виміряні ємності (і за бажання внутрішній опір). Застосунок розподілить комірки по групах так, щоб сумарні ємності груп були якомога рівнішими. Результат можна показати на схемі або вивантажити в CSV.

## Запуск

Застосунок статичний і не потребує збирання чи залежностей. Через ES-модулі його потрібно відкривати з HTTP-сервера, а не через `file://`.

```bash
npm start
```

Після запуску відкрийте http://localhost:8080. Можна також використати `python3 -m http.server` або розмістити файли на GitHub Pages.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` запускає тести і публікує сайт (`index.html`, `css/`, `js/`) при кожному push у `main`. Також його можна запустити вручну на вкладці **Actions** (Run workflow).

Одноразове налаштування: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Адреса сайту: `https://<користувач>.github.io/battery_ide/`.

## Тести

```bash
npm test
```

Тести перевіряють геометрію (немає перекриттів, групи суцільні, послідовні з'єднання є), вписування в корпус, калькулятори, балансування та генерацію SVG.

## Структура

| Файл | Призначення |
|---|---|
| `js/cells.js` | база комірок |
| `js/layout.js` | розташування комірок, групи, шини, характеристики пакета |
| `js/fit.js` | вписування в корпус: прямокутний і довільної форми |
| `js/tools.js` | калькулятори та балансування |
| `js/analysis.js` | розрахунок струмів у комірках і перемичках |
| `js/bms.js` | підбір і план підключення BMS |
| `js/schematic.js` | електрична схема підключення BMS (провідники різних мереж не перетинаються) |
| `js/routing.js` | траси дротів BMS (від краю або центральним каналом), перевірка перетинів, нарізка стрічки, зазори між шинами |
| `js/presets.js` | типові збірки за застосуванням |
| `js/scene3d.js` | опис 3D-сцени (без залежностей, тестується) |
| `js/view3d.js` | 3D-перегляд на three.js |
| `vendor/three/` | three.js r160 (MIT), вантажиться лише при відкритті 3D |
| `js/render.js` | генерація SVG |
| `js/main.js` | інтерфейс |

> Параметри комірок орієнтовні, звіряйте їх з даташитом. Схеми є допоміжними: збирайте акумулятори з BMS і запобіжником, дотримуйтеся техніки безпеки.
